# 照着拍 v0.7：图与证据来源

本版参考图库沿用20张：14张原创AI日常示例、2张真实历史赫本摄影、4幅真实画作；出处和权限边界见[v0.6素材账本](image-sources-v0.6.md)。没有把生成图当明星照片、实际打卡地或用户实拍。

新增 `public/images/review/scenarios.png` 是本次使用图像生成工具创建的四格使用情境图，原文件保留在生成目录。它用于解释产品场景，不是访谈照片、真实用户样本或算法评测数据。

两版各6张SVG设计图由 `scripts/build-review-docs.py` 生成，定义上传入口、用户流程、模型时序、构图和相机线框；名称、色彩对应各版。截图按 `animations: disabled` 完成转场动画后导出，用于核对真实实现。

用户感受引用本次对话的真实原话，证据范围为1位需求提出者的原型反馈／需求陈述。未使用无法核实的社交媒体感言，也未声称完成目标人群访谈。PRD中的8组配对测试与80张真实图评测均为待执行计划。
