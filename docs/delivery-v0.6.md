# 照着拍 v0.6：先看手册，再体验两个版本

## 可以直接阅读

[下载图文产品手册 PDF](../downloads/照着拍-产品手册-v0.6.pdf)。PDF 包含实际截图，可以直接打开，不需要先部署网页。

[完整 PRD](prd-v1.5.md) 已按 9 个页面逐项写明：点哪里、到哪里、怎样返回、怎样保存、失败时怎样继续。两种风格功能一致，另有 [截图目录](ui-preview/easy-v0.6/README.md)。

## 体验网页：按这几步操作

1. 在 [双版本 ZIP 文件页](../downloads/zhaozhepai-comparison-v0.6.zip)，点下载按钮，下载 ZIP。
2. 在电脑上解压。找到里面 **直接看得到 `index.html`、`classic.html`、`notebook.html`、`handbook.html`、`assets`、`images`、`models`、`vision`、`guide` 的文件夹**。
3. 到你原来的 Netlify 项目，打开 **Deploys** 页面，把上面的 **整个文件夹** 拖到手动上传区域。不要只拖 index.html，不需要逐个上传文件。
4. 等显示 **Published** 后，打开你的体验网址。首页选 A 暖色版或 B 笔记版；点右上角“怎么用”能看到手册。
5. 手机上可以打开同一个 HTTPS 网址，允许使用相机。电脑也会显示手机界面；没有摄像头时可以先看示例、参考和手册。

你现有的 https://kaleidoscopic-starburst-62c6b2.netlify.app/ 不会因为 GitHub 更新而自动升级，需要你完成第 3 步的上传。本次没有声称已经替你重新发布这个站点。

## 一眼检查有没有传对

打开你网址后加 `/preview-manifest.json`，应看到 `version: "0.6.0"`。若出现 404，多半是只上传了 HTML 或文件夹层级不对。返回第 2 步，确认该文件夹里直接有 index.html，再上传整个文件夹。

如果浏览器开的是 `file:///.../index.html`，那是电脑文件，不是体验网页。产品相机和模型需要从网址运行；手册 PDF 可以直接打开。

## 这版能体验什么

20 张参考、图文引导、四个 TAB、两人拍法、现场光影、手动风景站位、实际相机和本地人体检测、重拍、调色、原片导出、收藏及本地保存。

AI 风景分析的前后端已接好，但没有配置真实模型服务。这个静态 ZIP 会明确提示未开启；你可以自己选站位、从参考拍或看内置示例，不会显示伪造的图片分析结果。完整模型功能需要单独部署 Node 服务并安全配置模型环境变量。

原 v0.4 和 v0.5 ZIP 都保留，v0.6 不覆盖旧作品。A/B 共享同一站点的浏览器收藏和记录，便于公平比较视觉风格。
