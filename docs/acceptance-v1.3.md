## 尚未验证与边界

没有 iPhone Safari / Android Chrome 物理设备的相机、系统相册保存、持续发热与语音实际效果验收。相机自动化使用 Canvas MediaStream，语音使用测试替身；不冒充真机拍摄。

未配置真实模型凭证，云端测试使用模拟上游。现场用光为编辑方案和用户选择，不是实时光向检测；人物框亮度含背景与衣物，不是肤色或曝光质量评分。滤镜不重打光，不增加网页相机硬件控制能力。

Netlify 仍由用户手动上传，本环境未验证线上已更新。电脑本地双击 HTML 不能作为 HTTPS 网站运行；已有打开说明的原生 file:// 行为此前受受管 Chromium 策略阻止，未声称在 Mac 上实测。
