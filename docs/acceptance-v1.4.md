## 保留原版

- 对照实施前保存的 60 个文件 SHA-256，原有 `src/`、`public/`、`server/` 文件、`index.html` 和 v0.4 ZIP 均无变化。

## 功能验证

- `npm test`：**60 通过，0 失败，0 跳过**。新增 6 项覆盖现场取舍、动作与构图约束、保留偏好冲突、基于已拍人物范围的反馈，以及主观光线建议不伪造测量。
- `npm run build`：TypeScript 与 Vite 三入口生产构建通过。
- 原版 20 项与新版 7 项浏览器场景最终均通过。首次新版运行出现测试定位器名称匹配过宽，修正为精确匹配后重跑通过。
- **最终 ZIP 解压后的静态站点：新版 7 项完整场景再次全部通过**，包含对比页打开 A/B、收藏搜索、无参考进入、现场光线与空间限制、真实 Blob 保存与删除、刷新恢复、连续拍摄、目标快照、反馈冲突和存储失败反馈。静态站点没有开发服务器或云端模型参与。
- 390 × 844 手机布局检查无横向溢出，相机的动作提示与下一张修改并存时快门在视口内可达。1440 × 1000 桌面保持手机宽度界面。
- ZIP 清单中的 29 个文件逐个 SHA-256 校验通过；两个 HTML 引用的编译资源存在，ZIP 根目录包含选择首页。HTML、图片、模型及 WASM 均随包交付。

## 尚未验证和当前边界

- 浏览器自动化使用 Canvas MediaStream 测试相机输入，检测通过本机真实模型运行。未把它描述为实际手机摄像头测试；iPhone、Android、Safari 仍需设备体验。
- 没有实际模型 API 密钥，没有真实云端调用验收。前后端接口能力保留，静态版明确告知不可使用深度解读；现场适配依赖用户选择条件。
- 小卡为当前浏览器 IndexedDB，不具备账号同步；不保证浏览器清理存储后仍可恢复。
- 未部署到用户的 Netlify 站点。GitHub 更新只提供可下载包，需在 Netlify 的 Deploys 区域重新上传完整文件夹。
