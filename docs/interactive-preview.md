# 打开可交互的「照着拍」

截图只能查看外观。以下体验包包含新版网页、图片、人体识别模型和运行文件；完成上传后，才能获得可点击操作、申请相机权限的 HTTPS 网址。

## 用电脑打开，只需要三步

1. **下载并解压。** 打开 [体验包下载页](../downloads/zhaozhepai-preview-v0.3.zip)，点击文件右上方的向下箭头 **Download raw file**。这是私有仓库，请先登录有权限的 GitHub 账号。下载后解压，找到直接包含 `index.html` 的文件夹；文件夹名称由解压软件决定。
2. **上传网页。** 打开 [Netlify Drop](https://app.netlify.com/drop)，按提示登录；首次使用可选择 GitHub 登录。把上一步找到的文件夹整体拖入上传区域。这个文件夹内应直接包含 `index.html`、`images`、`models`、`vision`。不用填写构建命令，也不用上传整个源码仓库。
3. **打开生成的网址。** 上传完成后，打开 Netlify 给出的 `https://…netlify.app` 网址。这个才是产品体验地址。可以收藏它，也可以发到自己的手机打开。

上传后的网页可供持有链接的人访问；GitHub 源码仓库仍是私有。包内仅有应用运行文件和原创示例，不含个人照片、密钥或后端源码。是否需要注册、验证账号，以托管平台当时的页面为准。

## 更新已经上传的网站

应用当前版本为 0.3.0。旧 v0 / v0.2 压缩包不包含双人协作改动。仓库更新不会自动更新手动托管的 Netlify 站点：请下载新版 ZIP、解压，在现有项目的 Deploys 页重新上传直接包含 `index.html` 的文件夹，等 Published 后刷新原网址。

## 第一次怎么体验

点击「先用一张示例试试」→ 等待「已识别人像」→ 默认只选构图、动作自由，也可再选一项重点 →「确认目标，交给拍摄者」→ 一起看目标卡，交接手机 →「我来拍，打开相机」→ 允许相机权限 → 拍摄后一起选择保存，或给下一张一个调整。

首次识别要加载模型，可能需要等待。电脑没有摄像头时，可以先体验选图和目标编辑，再用手机系统浏览器打开同一网址拍摄。

**云端深度解读尚未接入。** 本地人体识别和上述核心交互不需要 API 密钥。照片只保留在当前浏览器会话，刷新会清空，请先保存。

## 常见情况

- **压缩包不能在 GitHub 预览：** 正常，请点向下箭头下载，不是在 GitHub 内打开应用。
- **双击 HTML：** 新版会提供从体验网址打开的说明。请按上面的步骤上传整个文件夹；直接打开本地文件不能正常运行相机与模型。
- **生成的网址显示 Page not found：** 先打开网址的首页（只保留 `https://网站名.netlify.app/`，去掉后面的路径）。仍显示 404 时，检查上传目录：打开要上传的文件夹，应直接看到 `index.html`，不需要再打开任何子文件夹。旧包的正确目录叫 `zhaozhepai-preview`，位于解压目录里面；重新上传这一层即可。新版 ZIP 已把首页放在压缩包最外层，避免多包一层。
- **不能打开相机：** 使用生成的 HTTPS 网址，在浏览器地址栏的权限设置中允许相机；手机优先使用 Safari 或 Chrome。

## 开发维护

在项目目录执行 `npm run build`，再用 Python 3 执行 `python3 scripts/package-preview.py` 重新生成体验包。包内 `preview-manifest.json` 记录构建文件哈希。静态体验包不部署 Node API；需要云端解读时，按根目录 README 部署完整服务并配置服务端凭证。

本次将 v0.3 ZIP 解压至独立目录并校验全部 16 个构建文件的哈希，在不运行开发服务器或 Node API 的静态服务器上通过 17 项浏览器检查，包含双方交接、默认动作自由、反馈改变下一张目标、语音按需触发和停止、原有涂抹/裁切/权限/镜像/保存等流程。使用真实人体识别模型和测试媒体流；它不代表公网已发布，也不代表手机真机验证已完成。详细边界见 [验证记录](acceptance-v1.2.md)。
