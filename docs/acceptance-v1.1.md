## 本机验证

环境：Node.js 24.19.0，npm 11.9.0，系统 Chromium，桌面 1440×1000、手机视口 390×844。

- 40 项规则/后端测试：归一化选区、擦除、平移缩放不变性、左右镜像、遮挡优先、持续成功与即时丢失、文本落到真实约束、不支持文本、图像事实未知、schema/请求体限制、Gemini 和 OpenAI 适配器的模拟上游结果。
- 14 项浏览器用例：实际本地模型在四张参考、空白帧、双人合成图与视频帧上推理；涂抹历史；模式切换；文字修改和镜像选择；上传/取消/错误；云请求同意流程；权限失败；画面无人暂停；原片像素没有辅助线；镜头切换释放旧轨道；前置保存与预览方向一致；后台停止并恢复；手机尺寸可见快门。
- `npm run build`：TypeScript 与生产构建通过。Node 静态服务的生产页面实际加载本地模型成功，浏览器没有未捕获错误，健康接口如实返回云模型未配置。
- `git diff --check`：没有空白错误。模型文件经 SHA-256 检查；npm 模型分发包下载与 registry 提供的 SHA-512 完整性值一致。

摄像头相关自动化使用测试专用 Canvas MediaStream，向真正的 MediaPipe VIDEO 检测器提供生成图片和空白画面。测试没有替换识别结果，没有用预填骨架或固定成功文案代替检测。**这些证据仅覆盖浏览器集成与程序逻辑，不代表物理相机、iPhone Safari 或 Android Chrome 的实际试拍效果。**

云端成功和异常分支中的上游行为使用模拟服务或结构校验测试；没有真实付费大模型调用，没有虚构模型可用性、用户满意度或效果提升。

截图在本工作区 `artifacts/`：首页/参考的桌面和手机截图、相机桌面和手机截图、成片页、生产参考页。相机截图中的人物来自自动化视频输入，不能充当真实演示视频。
