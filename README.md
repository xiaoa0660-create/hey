# 照着拍

把你喜欢的参考照片，变成朋友可以执行的一步构图调整。

这是基于 [产品说明](docs/product-brief.md) 的可操作 Demo。它围绕朋友互拍的具体任务：选参考、选一个构图目标、确认试拍里的人物、照着指引重拍，再由用户选择和保存喜欢的照片。

## 打开与开发

需要 Node.js 22.18+。已验证的环境为 Node.js 24.19.0、npm 11.9.0。

```bash
npm ci
npm run dev
```

开发服务器监听 5173 端口。生成生产构建及可直接打开的单文件 Demo：

```bash
npm run build:demo
```

下载或复制 `dist/照着拍-Demo.html`，用现代桌面浏览器打开，无需服务器和 API 密钥。手机文件预览器可能不执行 JavaScript；手机试用建议通过 HTTP 服务打开正常构建。`npm run preview` 可以检查生产构建。云环境准备和启动说明见 [cloud-start.md](docs/cloud-start.md)。

## 60–90 秒演示

1. 首页点击「用咖啡馆示例试试」。
2. 选择「这里的留白」和「左侧」，点击「照这个目标试拍」。
3. 查看示例第一次试拍：人物位置偏左，指引要求人物在最终画面里靠右。可以展开解释、拖动人物框或导出指引卡。
4. 查看调整后的一张，在并列或滑动模式比较。选择喜欢的照片并保存，选择之前那张也会导出正确照片。
5. 重新开始，上传自己的参考与试拍，确认裁切和人物框。用同一张照片与相同人物框会得到「已经比较接近」，调整框的位置或大小会改变建议。

## 已实现

- 手机和桌面的完整五阶段流程，暖白、墨绿、摄影大图及取景器标注。
- JPG、PNG、WebP 等浏览器可解码图片的真实上传，设备支持时可从文件选择器拍照；读取失败保留已有会话。
- 原图 / 3:4 / 4:5 参考画幅、拖动与等比例缩放裁切框；试拍固定为参考画幅。
- 人物框拖动、四角缩放、方向键调整及精细滑条。确认框之后再比较。
- 分别计算人物中心、可见人物框高度和左 / 右 / 上侧空间，每次只给一个调整动作。
- 超出画面的移动目标先给缩小人物占比的指引；接近参考不强行调整，重拍变差如实说明。
- 并列 / 滑动比较、选择任一张照片、继续调整、切换目标。
- 实际 PNG 指引卡导出与 JPEG 照片保存；照片按当前裁切导出且不包含标注。

## 实现依据与边界

**真实上传走手动确认与真实几何计算，目前没有 AI 人物识别服务。** `src/lib/vision.ts` 保留可替换适配接口。接入时由服务端保管密钥、说明照片传输，并在失败或低置信度时保留手动确认路径。

示例明确标为「示例体验」，使用同一张 AI 生成素材的三种裁切表现构图变化；人物边界按素材校准，不代表真实现场重拍或已验证的产品效果。生成素材在 `public/images/cafe-editorial.png`。

裁切坐标相对于方向校正后的原图，人物框相对于裁切后的画面，均归一化至 0–1。显示、规则与导出共用这些坐标。箭头表示人物在最终照片中应该靠近的方向，不推断真实机位、移动距离或焦距。留白使用人物边界到画面边缘的空间作为代理，不判断背景是否空旷。容差保存在 `src/lib/geometry.ts`，仅为 Demo 参数。

照片通过内存和对象 URL 保存在当前浏览器，清理会话释放资源；刷新会清空照片。单张上限 35 MB / 3200 万像素，浏览器不支持的 HEIC 等格式会提示改用 JPG。EXIF 方向由浏览器解码后用 Canvas 归一化；未覆盖每种手机、相机及浏览器的格式组合。

首版面向单人照片，暂不含实时取景、双机同步、姿势、灯光或多人分析。需求价值仍需通过真实朋友互拍测试验证；没有预填用户反馈或效果提升数据。

## 验证

```bash
npm test
npm run build:demo
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:e2e
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:demo
```

若没有系统 Chromium：先运行 `npx playwright install chromium`，再运行 `npm run test:e2e`。

20 项规则测试覆盖无差异、四向位置、比例、三侧空间、画面内目标、变好 / 变差、无效框、裁切坐标转换及拖拽边界。8 项浏览器测试覆盖完整示例、实际图片上传、框编辑、目标切换、错误回退、替换参考清理旧结果、两种照片选择与下载、PNG 指引输出，以及 360 / 390 px 窄屏。

另用浏览器核对桌面与手机视觉及导出图片。单文件检查通过本地 HTTP 路由提供 HTML，并在浏览器断网状态下运行示例、上传和下载，验证不依赖外部资源。本环境的托管浏览器禁止 `file://`，因此未在此环境直接双击文件验证。自动化检查基于 Chromium；Safari 真机拍照入口尚未验证。
